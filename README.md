# 🥊 สังเวียนประลองมวยวัด (ARENA LIVE) - TikTok Live Interactive Game

เกมต่อสู้แบทเทิลรอยัลมวยวัดบน TikTok Live (สไตล์ `@amsmanoverse`) หน้าจอแนวตั้ง 9:16 ที่จำลองบรรยากาศงานวัดไทย (ชิงช้าสวรรค์, เจดีย์ทอง, หลอดไฟนีออนงานวัด, สปอตไลท์ส่องฟ้า, เงาฝูงชน) พร้อมระบบสังเวียนวงกลมเรืองแสงที่คนดูในไลฟ์สามารถส่งคอมเมนต์, เคาะใจ (Likes), และส่งของขวัญ (Gifts) เพื่อต่อสู้ ชก ต่อย ฟัน ผลักคนอื่นให้ตกเวที!

---

## 🚀 ลิงก์ระบบหลัก (รันที่พอร์ต 3000)

- **หน้าจอรวมเกม + แอดมิน (Unified App):** [http://localhost:3000](http://localhost:3000)
  - มีปุ่ม **"ซ่อนเมนูแอดมิน"** เพื่อพับแผงควบคุมให้เหลือหน้าจอเกม 9:16 สวยงาม
  - มีปุ่ม **"ขยายเต็มจอ (OBS)"** หรือนำ URL `http://localhost:3000` ไปใส่ใน Browser Source ของ OBS Studio (ตั้งขนาด 1080 x 1920)

---

## 📜 กติกาการเล่นและการแปลงปฏิสัมพันธ์ (Interactivity Rules)

### 1. สายฟรี (Free-to-Play)
- 💬 **พิมพ์ `เข้า` หรือ `JOIN`:** เสกตัวละครคนดู (ใช้รูปโปรไฟล์ TikTok จริง) โดดร่ม/ดรอปลงสู่สังเวียนมวยวัดทันที
- ❤️ **เคาะใจ (Likes) ครบ 30 ครั้ง:** ได้รับพลังบัฟ เลือดเพิ่ม (+HP) และหมัดหนักขึ้น
- ➕ **กดติดตาม (Follow):** ได้รับ **โล่บาเรียสีฟ้า (Shield) 🛡️** ป้องกันการโจมตี
- 🔗 **กดแชร์ไลฟ์ (Share):** สปีดความเร็วพุ่งหลบและโจมตีไวขึ้น 2 เท่า (Speed Boost ⚡)

### 2. สายเปย์ / ระบบของขวัญ (Gifts & Monetization)
- 🌹 **1–4 เหรียญ (บัฟหมัด / กุหลาบ):** เพิ่มเลือด + ดาเมจหมัด
- ⚔️ **5–29 เหรียญ (อาวุธ - ดาบมวยวัด):** ถือดาบฟันศัตรูกระเด็นไกลขึ้น x2 ดาเมจรุนแรง
- 🛡️ **30–99 เหรียญ (อุปกรณ์ - โล่เกราะทอง):** ได้รับเกราะเหล็กสะท้อนดาเมจ
- 💥 **100–299 เหรียญ (สกิล - คลื่นกระแทก Shockwave):** ปล่อยคลื่นพลังระเบิดศัตรูรอบตัวให้กระเด็นตกเวที
- ☄️ **300–999 เหรียญ (อัลติเมท - ดรอปดาวตก / ฟ้าผ่า):** เรียกสายฟ้าฟาดกลางเวทีกวาดล้างคู่ต่อสู้
- 👹 **1000+ เหรียญ (บอสยักษ์):** ขยายร่างตัวละครเป็นยักษ์ 3 เท่า เหยียบกระแทกสังเวียน
- 👻 **พิเศษสุด! "ตายแล้วส่งของขวัญ = ฟื้นชีพทันที" (Revive on Gift):** หากตัวละครถูกชกตกเวทีกลายเป็นวิญญาณลอยขึ้นฟ้า หากผู้ชมส่งของขวัญ (เช่น กุหลาบ 1 ชิ้น) จะเสกตัวละครกลับมาชุบชีวิตคืนชีพลงสังเวียนได้ทันที!

## 🏆 ระบบจบรอบและการชิงแชมป์ (Round & Victory)

- มีตัวนับเวลาถอยหลังรอบการประลอง (Round Timer)
- เมื่อเหลือผู้รอดชีวิตคนสุดท้าย (Last Man Standing) หรือหมดเวลานับคะแนน KO:
  - ประกาศ **แชมเปียนประจำรอบ (Victory Modal)** พร้อมถ้วยรางวัล 🏆, แสงสปอตไลท์, จำนวนน็อค (KO Count)
  - บันทึกชื่อขึ้นทำเนียบ **กระดานแชมป์เปียน (Champion Leaderboard)**
  - รีเซ็ตรอบใหม่เพื่อเริ่มประลองรอบต่อไปโดยอัตโนมัติ
